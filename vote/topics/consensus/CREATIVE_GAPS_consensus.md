### Tie-Breaking Analysis

**Pattern:** Most conflicts follow the pattern M+L+A vs P+S — the Morphologist+Lexicographer+Aestheticist approve, while the Phonologist+Semanticist reject.

- **P rejects**: Nearly all end in a consonant (coda violation): alon, faul, fraid, kwaiet, laif, seif, voys, welkom, wing. Phonologist would accept with vowel-final forms (alo, faulu, fraide, laife, seife).
- **S rejects**: Claims these are decomposable from existing atoms (alon→wan-stat, bow→bodi-daun, faul→fal duplicate, wing→frai-part).

**Key decisions needed:**
1. **Should consonant-final roots be accepted?** The Q3 "grandfather" rule allows existing consonant-final forms. These are NEW words. VELA precedent: forti, pasi, Loru, sunap (all vowel-final). Strictly, these should be rejected UNLESS the user overrides.
2. **laif — the exceptional case**: The Semanticist scored it 🤔 (not ❌), noting "top-50 human concept" and "borderline exceptional." This is the strongest candidate for exception.
3. **touch — 5th sense paradigm**: Phonologist rejects on coda, Aestheticist suggests tusha. Semanticist strongly approves.
4. **sey — duplicate**: Morphologist and Semanticist say tok/tal already cover "say." P+L+A approve. This is a semantic overlap concern.
