# Morphologist Vote — Q2: Atoms vs Compounds (First Round)

**Agent:** vela_morphologist (deepseek-v4)
**Date:** 2026-05-14
**Result:** 26 ATOM / 4 COMPOUND (86.7% / 13.3%)

## Key Insight
When forced to apply the user's criterion (primitivo = simple/corto/frecuente, compuesto = solo si obvio y transparente, NO forzar), the morphologist concluded **almost everything should be atomic**.

The 4 compounds identified:
| Word | Compound | Reason |
|------|----------|--------|
| bakpak | bak-pak | Already transparent in English (back + pack), no ambiguity |
| fri.dom | fri-dom | Derivational suffix "dom", not descriptive |
| erkweik | ert-kweik | Natural decomposition (earth + shake), found across languages |

NOT compounds: yel-kat (lion), blak-bird (crow), long-nos-animal (elephant) — all rejected as taxonomically arbitrary, reducing animals to single features, and creating collision with descriptive phrases.

## Critical Realization from User
The user's objection: if `yel-kat` = lion, then what is "gato amarillo" in VELA? Since VELA uses adjective-prenominal position, `yel kat` (with space) = yellow cat (description), but `yel-kat` (with hyphen) = lion (name). This creates inherent semantic collision. Either:
1. The hyphen is an artificial lexical marker (not natural)
2. Or we abandon color+animal descriptive compounds entirely

The morphologist's result essentially chose Option 2: animals (and most clothing, body parts, tools) remain atoms. Only transparent, non-descriptive compounds survive.

## Relevance for Reformulated Vote
This will inform the new Q2 formulation: compounds ONLY when:
- The decomposition is unique and non-ambiguous
- It does NOT create collision with natural descriptions
- It is already "folk-transparent" in source languages
