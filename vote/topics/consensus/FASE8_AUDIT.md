## Discovery

After user approval, a verification scan of LEXICON_BASE.md revealed that **3 of the 12 approved words already exist** in the lexicon. The committee reviewed proposals without full lexicon access (dossier pattern limitation), and the original Fase 8 text writer did not recall these existing forms.

### Collision: `grin` = gray, not green

The lexicon already contains:
- `gren` = green (color)
- `grin` = gray (color)

The user approved `grin` for "green" based on English truncation pattern, but this collides with existing `grin` = gray. 

**Resolution:** The color "green" already exists as `gren`. No action needed. The word `grin` remains = gray.

## Process Lesson
The dossier pattern (embedding source text instead of giving agents file access) has a known risk: agents cannot verify if a word already exists. For future Fase 8+ gap reviews, the dossier should include a **"Pre-existing Check"** section listing all potentially related words from the lexicon.
