## Final Rule

### Basic Mechanism

| Stem ends in | Plural | Syllables added | Example |
|---|---|---|---|
| **Vowel** (a, e, i, o, u) | **-n** | 0 | siti → siti-n |
| **Consonant** (Q1-legal: n, m, l, r, s) | **-en** | +1 | man → man-en |

### Case Interaction (case → plural)

| Form | Singular | Plural |
|------|----------|--------|
| Nominative | man | man-en |
| Genitive | man-se | man-se-n |
| Locative | man-to | man-to-n |

The case suffix always ends in a vowel (-e, -o), so the plural always surfaces as bare **-n**.

### Examples

```
man      → man-en      (men)
siti     → siti-n      (cities)
hous     → hous-en     (houses)
famili   → famili-n    (families)
kat-a    → kat-a-n     (cats)

man-se   → man-se-n    (of the men)
siti-to  → siti-to-n   (in the cities)
```

## Rationale

1. **Phonotactic**: -n is Q1-legal (sonorant coda). No new phonotactic rules.
2. **Morphological**: Clean case stacking under case→plural order. One inflection class.
3. **Lexical**: Cross-linguistically top-5 plural strategy. Works for English, Mandarin, Japanese, Spanish learners.
4. **Semantic**: Passes the 5-year-old test. Zero parsing ambiguity.
5. **Aesthetic**: Resonant hum. Adapts to the word's own phonology. Breathes.
