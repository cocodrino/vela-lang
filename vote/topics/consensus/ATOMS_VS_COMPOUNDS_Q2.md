## User's Refined Philosophy

> "Si la palabra compuesta es CORTA, tiene SENTIDO, y SUENA BIEN → usar compuesta.
> Si el átomo es CORTO, SIMPLE, SENCILLO, y la compuesta NO → usar átomo.
> NO compuestos complicados. NO infantilismo."

## Compound Quality Gate (4 Tests, ALL must pass)

A word MAY be a compound ONLY if:

1. **SHORT**: ≤ 2 roots (3 máximo si son todos monosílabos). NO `long-nos-animal` (4 raíces, infantil).
2. **MEANINGFUL**: El significado es ÚNICO y NO AMBIGUO. NO `yel-kat` (gato amarillo ≠ león).
3. **SOUNDS GOOD**: Pasa el "cradle test" del esteticista — puede cantarse en una canción de cuna sin despertar al bebé.
4. **NOT INFANTILE**: No reduce un animal/objeto a una sola característica física. NO `big-fish` (ballena), `ait-leg-bug` (araña).

## Categories of LEGITIMATE Compounds

| Category | Example | Why Passes |
|----------|---------|-----------|
| **Functional** | `moni-bag` = wallet | bolsa para dinero — funcional, no descriptivo |
| **Institutional** | `sik-hous` = hospital | casa para enfermos — sistema/institución |
| **Derivational** | `fri-dom` = freedom | sufijo de estado (-dom), no descripción |
| **Already-transparent** | `bak-pak` = backpack | Ya es transparente en inglés; sin ambigüedad |
| **Cross-linguistic** | `ert-kweik` = earthquake | Tierra + sacudida; transparente en TODAS las lenguas |
| **Body relation** | `hand-kloth` = glove | SÓLO si ambas partes son inequívocas (mano + tela = guante) |

## Categories of PROHIBITED Compounds

| Category | Example | Why Fails |
|----------|---------|-----------|
| **Color+animal** | `yel-kat` = lion | Colisión con "gato amarillo" como descripción |
| **Size+animal** | `big-fish` = whale | Factualmente incorrecto; ballena ≠ pez |
| **Feature+animal** | `horn-animal` = deer | Reduce a 1 característica; no único (rinoceronte también tiene cuerno) |
| **Count+animal** | `ait-leg-bug` = spider | Infantil; cuenta patas como definición |
| **Function+tool** | `hit-tul` = hammer | Demasiado genérico (puños, mazos también "golpean") |
| **3+ roots** | `tree-klaim-animal` = koala | Largo, infantil, descriptivo |

## Decision Matrix for Any New Word

```
Is there a compound that passes ALL 4 tests?
├─ YES → Use compound
└─ NO  → Is the atom short, simple, and sonorous?
    ├─ YES → Use atom
    └─ NO  → Reject or redesign the word
```
