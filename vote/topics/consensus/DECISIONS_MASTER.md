## Q1: Fonotactics — STRICT (C)V

**Decision:** Reform all words (existing + new) to strict open-syllable (C)V structure.

**Rules:**
- Every syllable ends in a vowel
- Word-final consonants: only /n, m, l, r/ or vowel
- No coda clusters (lf, rk, ks, nt, nd, etc.)
- No internal codas (every syllable must be open)
- Onset clusters: maximum 2 consonants (skw → sw)
- Invalid diphthong /ou/ → /au/

**Impact on existing lexicon:** ~30 words need reform (ok→oke, haid→haide, dog→dogi, nos→noso, etc.)
**Impact on new words:** 94 of 186 need phonotactic amendment.

## Q2: Atom vs Compound — TIERED SYSTEM + QUALITY GATE

**Decision:** 3-tier vocabulary with strict criteria for compounds.

### Tier Structure

| Tier | Count | Description |
|------|-------|-------------|
| Tier 0 | ~50 | Primitivos absolutos — survival vocabulary |
| Tier 1 | ~150 | High-frequency shortcuts — what natural languages treat as atoms |
| Tier 2+ | ~500+ | General vocabulary — atom by default, compound only if passes Quality Gate |

### Compound Quality Gate (ALL 4 must pass)

1. **SHORT**: ≤ 2 roots (3 max if all monosyllabic). NO `long-nos-animal`.
2. **MEANINGFUL**: Meaning is UNIQUE and NON-AMBIGUOUS. NO `yel-kat` (collides with "yellow cat").
3. **SOUNDS GOOD**: Passes "cradle test" — can be sung in a lullaby.
4. **NOT INFANTILE**: Does not reduce an animal/object to one physical feature.

### Legitimate Compounds (✅ Allowed)

| Compound | Meaning | Category |
|----------|---------|----------|
| bak-pak | backpack | Already-transparent |
| moni-bag | wallet | Functional |
| sik-hous | hospital | Institutional |
| fri-dom | freedom | Derivational |
| ert-kweik | earthquake | Cross-linguistic |

### Prohibited Compounds (❌ Rejected)

| Compound | Why Rejected |
|----------|-------------|
| yel-kat (lion) | Color+animal; collides with "yellow cat" description |
| big-fish (whale) | Factually incorrect; whale ≠ fish |
| horn-animal (deer) | Reduces to 1 feature; rhino also has horn |
| ait-leg-bug (spider) | Infantile; counts legs as definition |
| hit-tul (hammer) | Too generic; fists also "hit" |
| tree-klaim-animal (koala) | 3+ roots, infantile, descriptive |

### Committee Convergence on Q2

All 5 specialists independently concluded ~90% atoms, 0% descriptive compounds:

| Specialist | Atoms | Compounds | Key Argument |
|-----------|-------|-----------|-------------|
| Morphologist | 87% | 13% | "mane-cat only applies to males" |
| Aestheticist | 90% | 10% | "yellow-cat not inevitable" |
| Lexicographer | 93% | 7% | "core animal names = atoms" |
| Phonologist | 93% | 7% | "basic animals, body parts = atoms" |
| Semanticist | 90% | 10% | "big-cat is too broad" |

## Q3: Vowel-Final — REFORM NEW WORDS

**Decision:** New proposed words should end in vowels or sonorants (/n, m, l, r/). Existing lexicon preserved as grandfathered.

**Rationale:** The "cradle test" — words ending in hard plosives (-t, -k, -d, -p) are too harsh for VELA's lullaby aesthetic.

**Application:** Reform ~94 of 186 new words (not the existing ~30 grandfathered violations).

## Q4: Etymology — HYBRID (4-1 Vote)

**Decision:** English roots for everyday concrete words; Latin/Greek roots for abstract/scientific/formal words.

### Voting Record

| Specialist | Model | Vote |
|-----------|-------|------|
| Lexicographer | glm-5.1 | **C — Hybrid** |
| Phonologist | kimi-k2.6 | **C — Hybrid** |
| Semanticist | deepseek-v4 | **C — Hybrid** |
| Aestheticist | kimi-k2.6 | **C — Hybrid** |
| Morphologist | deepseek-v4 | **A — English Only** (dissent) |

### Rule

| Semantic Domain | Source | Examples |
|----------------|--------|----------|
| Physical, tangible, everyday | English | dog, water, eat, hat, bank |
| Abstract, formal, scientific | Latin/Greek | justiso, kulturo, ekonomi, sistemo |
| Animals | English (default) | laigon, elefant, ber |
| International animal names | Latin/Greek | elefanto (if international form preferred) |

### Dissenting Argument (Morphologist)

"A single etymological source eliminates the arbitrary tier-boundary problem — where does 'everyday concrete' end and 'science/abstract' begin? Consistency—one source, one rule, no exceptions—is the most beautiful morphological architecture."

**Response:** The semantic criterion (tangible vs. abstract) is principled and testable, aligning with cognitive acquisition order.

## Previous Unanimous Decisions (Earlier Phases)

### Profession Suffix
- **`-po` universal** for ALL professions
- Rejected: `-ist`, `-er`, dual systems
- Examples: doktr-po (doctor), tekr-po (teacher), wrk-po (worker)

### Possessive System
- **`-se` only** — eliminated `-f` forms entirely
- mi-se (my), yu-se (your), li-se (his/her), wi-se (our), de-se (their)

### Plural + Case Order
- **ROOT → CASE → PLURAL**
- Example: `man-se-n` (man + genitive + plural) = "of the men"

### Adjective Suffix `-im`
- **Eliminated entirely**
- Adjectives marked by position (prenominal) or predicative construction

### State/Location Suffix
- Abstract state: **bare adjective** ("in freedom" = `in fri`)
- Spatial/temporal location: **`-to`** ("in the house" = `in hous-to`)

### Numbers
- 0–10: atomic
- 11–99: decimal compounding
- 100 = `kent`, 1000 = `mil`, 1M = `miliyun`
