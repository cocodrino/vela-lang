The lexicographer and aestheticist independently identified the same problem: the batch sounds like "English spelled phonetically" rather than VELA words. Words ending in hard plosives (-t, -k, -d, -p) abandon the soft-landing lullaby principle.

## ⚠️ Questions for User Decision

### Q1: Phonotactic Rules Clarification

The phonologist applied **strict** (C)V rules and found ~30 existing words invalid. Which interpretation is correct?

**Option A:** Strict — every syllable ends in a vowel; only /n,m,l,r/ word-finally. Reform existing ~30 words.
**Option B:** Permissive — (C)V is the *canonical* syllable, but word-final /d,t,k,g,s,p,f,sh/ are permitted as a practical concession (as the existing lexicon demonstrates).
**Option C:** Hybrid — (C)V for new words going forward, but grandfather existing violations.

### Q2: Atom vs Compound Balance

The morphologist says only **46 atoms** are justified, **135 should be compounds**. But compounds like `yel-kat` (yellow-cat = lion), `strip-kat` (stripe-cat = tiger), `blak-bird` (crow), `fut-kloth` (sock), `moni-bag` (wallet) may feel childish or impractical for adult conversation.

**Option A:** Strict — maximum simplicity, compounds for everything except ~50 Tier 0 primitives.
**Option B:** Pragmatic — allow ~150 atoms for common concepts (including animals, clothing, tools).
**Option C:** Hybrid — Tier 0 (~50) + Tier 1 (~100 shortcuts) as approved by the morphologist.

### Q3: Vowel-Final Convention

The aestheticist wants **all words to end in vowels or sonorants** (no final -t, -k, -d, -p). This would require adding vowels to ~94 words. But the existing lexicon has many words ending in these consonants.

**Option A:** Reform all — add terminal vowels to every word (English-pidgin → lullaby).
**Option B:** Preserve existing, reform new words only.
**Option C:** Selective reform — only for the ugliest words (score < 5).

### Q4: Latin Roots vs English Roots

The lexicographer suggests replacing English-only forms with Latin roots ending in -o: `ber`→`urso`, `wulf`→`lupo`, `foks`→`vulpo`, `dir`→`cervo`, `pis`→`paco`, `bank`→`banko`, `limit`→`limito`.

But this conflicts with the project's stated principle of English recognizability.

**Option A:** Latin priority for non-English speakers (Esperanto-style).
**Option B:** English priority for maximum accessibility (Toki Pona-style).
**Option C:** Hybrid — Latin for science/abstract, English for everyday.
