## Systemic Issues
1. **The "Loan Trap":** The lexicon often takes the easiest path (English loan) instead of the VELA path (Transparent Compound). 
2. **The 200-Atom Limit:** We are approaching the ceiling because we are treating "adapted loans" as atoms. If we compound more, we save atom slots for truly unique concepts.
3. **English Calques:** Many loans aren't "international scientific terms" but simply English words (e.g., `deploy`, `branch`, `plot`).

## Recommendations
1. **Purge Non-Scientific Loans:** Any loan that isn't a globally recognized scientific term (like `DNA` or `Atom`) should be replaced by a 2-3 root compound.
2. **Expand the Root Set:** To avoid "loan overload", we need more atomic roots for concepts like `state`, `function`, `value`, and `move`.
3. **Formalize the Emotion Model:** Use the "Emotion Clusters" as the mandatory template for all other abstract concept domains.
