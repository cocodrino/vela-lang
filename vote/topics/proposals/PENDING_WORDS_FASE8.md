## Committee Questions

### For ALL words:
1. **Phonotactics:** Does it pass strict (C)V? If it ends in consonant, what vowel should be added?
2. **Morphology:** Atom or compound? Does it pass the Quality Gate?
3. **Semantics:** Any collisions, polysemy, or homonymy with existing words?
4. **Lexicography:** Does the etymology align with Q4 hybrid policy (English everyday / Latin abstract)?
5. **Aesthetics:** Does it pass the "cradle test"? Beautiful, singable, lullaby-quality?

### Specific questions:
- **pasi** vs **pas** vs **paco**: Is `pasi` (Latin *pax*) the best form, or should it be shorter?
- **servi** vs **help**: Do we need both? Is `servi` distinct enough from `help`?
- **forti** vs **for** + **ti**: Is this a compound or atom? `for` already exists as preposition.
- **Loru** as proper noun: Should proper nouns follow phonotactic rules at all?
- **tugeter**: Compound (`tu-get-er` = to-gather-er) or atom? Too long for atom?
- **green**: Adjectives already don't use `-im`. Is bare root acceptable? But Q3 says vowel-final for NEW words.
