# R21 round 2 — form of the past suffix (-eda / -edi / -edo)
**Date:** 2026-10-26 · 5 Claude subagents, read-only

**Why a second round:** round 1 split 2-2-1 (`-eda` / `-edi` / `-edo`). The round-1 dossier listed only `-eda`, `-edi`, `-de`, `-di` as examples, so only the phonologist had evaluated `-edo`. The owner asked why `-edo` got so few votes; the answer was the dossier's bias, so all three finalists were re-evaluated with the same facts.

| Specialist | Ranking | Vote |
|---|---|---|
| Aestheticist | edo > edi > eda | **-edo** — the only back rounded vowel; contrasts with the -a/-i word-ends around it; `-eda` "melts into the -a citation sound" |
| Morphologist | edo > edi > eda | **-edo** — `-eda` parses as citation of a root *maked*; `-edi` likewise, since -i is also a citation vowel (`livi`); `-edo` parses only as root + edo |
| Lexicographer | edo > edi > eda | **-edo** — no collisions; keeps English "-ed" whole and matches Spanish/Portuguese -ado/-ido; `-eda` reads as a feminine participle in Romance, near `neda`/`needa` |
| Semanticist | edo > edi > eda | **-edo** — `-eda` ends in the present/citation marker -a; `-edi` blurs verb/adjective; no -o morpheme exists |
| Phonologist | eda > edi > edo | **-eda** — concern: `-edo` vs locative `-to` is a voicing-only contrast for Mandarin listeners; Arabic /o/ → [u] |

**Result: `-edo`, 4-1.**

**Orchestrator check of the dissent:** the phonologist's example `share-to` vs `shar-edo` is not a real pair. A vowel-final root keeps its vowel before a suffix (`si-ed`, so `share-edo`), which is one syllable longer than `share-to`. A real minimal pair would need a noun whose citation form equals a verb's bare root + `e`; none was found. The concern is recorded, not dismissed: watch for `-e` + `-to` / `-edo` near-pairs in new coinages.
