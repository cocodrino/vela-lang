## Observaciones

**Ventajas de compuestos:**
- Cada palabra nueva es transparente (sabes qué significa por sus partes)
- Solo necesitas memorizar ~50 primitivos
- Cero ambigüedad (una forma = un significado)

**Desventajas:**
- "yel-kat" para "león" puede sonar infantil
- "ait-leg-bug" para "araña" es largo (4 sílabas)
- "moni-sistam" para "economía" es más largo que "ekonomi"
- Conversaciones complejas se vuelven muy largas

**El morfólogo lo resuelve así:**
- Tier 0 (~50): primitivos absolutos (mi, yu, go, eat, water, big, good)
- Tier 1 (~100): atajos de alta frecuencia permitidos (ber, mous, rat, shart, shu, hat, pant, ring, bank, fon)
- Todo lo demás: compuesto transparente

Esta es la estructura que el morfólogo propone. ¿Te parece viable para uso adulto, o prefieres más atajos (Tier 1)?
