# Plural System Deliberation — Open Proposal + Vote

**Date:** 2026-05-16  
**Type:** Open deliberation — specialists PROPOSE options, then VOTE  
**Context:** VELA needs a plural system that satisfies: phonotactic consistency, learnability, brevity, and aesthetic quality.

## Current State (Problem)

- Grammar documents use **-s** as plural: `man → man-en`, `siti → siti-n`
- Resolved: plural is now `-n/-en` (see consensus). The prior `man-en` example is deprecated.
- Q1 already permits sonorant codas (-n, -m, -l, -r). -s is NOT yet legal.
- Genitive = **-se**, Locative = **-to**
- Order: case → plural (`man-se-n` = of the men)

## Constraints

- **-sa** is REJECTED by the user (aesthetically displeasing, too heavy: 2 extra syllables)
- **-s** is currently used but phonotactically inconsistent
- Solution must work with the existing 2-case system (-se, -to)
- Must be learnable for speakers of diverse L1 backgrounds
- Must not break segmentation (word boundaries should remain clear)
- Must be brief — VELA values concision

1. **PROPOSE** 1-3 distinct plural options (can be suffixes, particles, reduplication, vowel change, zero-marking, etc.)
2. **EVALUATE** each of your own proposals against your specialist criteria
3. **RANK** your proposals from best to worst

Be creative. Think beyond suffixes. Consider: reduplication, vowel mutation, particles, tone, zero-marking, infixes, circumfixes. Natural languages do plural in dozens of ways.
