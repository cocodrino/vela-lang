# Future Proposal — Transparent Compounds for Every Domain

**Status**: DRAFT — queued for future deliberation
**Author**: orchestrator (synthesis of user suggestion + prior consensus patterns)
**Topic**: Extending the "sik-hous" / "lern-hous" pattern to 7 additional domains

## Background
In the Lexicon Quality Audit (2026-05-13), the consensus unanimously approved transparent compounds for institution names: `sik-hous`, `lern-hous`, `buk-hous`, `eat-hous`. The user suggested this pattern should extend to careers/professions and other domains.

## Open Questions for Deliberation

1. **Should all professions end in `-man` / `-po` regardless of gender?** Or should gender-neutral forms exist?
2. **For sciences**: should the suffix be `-siens` or `-lern` (study)? E.g., `lif-lern` vs `lif-siens`.
3. **For vehicles**: should the pattern be `medium + thing` (`sky-thing`) or `thing + medium` (`thing-sky`)? VELA currently uses `sik-hous` (attribute + head), suggesting modifier-head order.
4. **For emotions**: is `hart-` too Eurocentric? Japanese uses `kimochi` (feeling), Chinese uses `xin` (heart), but many cultures do associate heart with emotion.
5. **How many atomic roots should be retained as exceptions?** The Lexicon Quality Audit left "~30 most frequent" as a placeholder. Should numbers, pronouns, and basic verbs be the only atomic words?

## Impact Estimation
If these 7 domains are fully compoundified:
- **Atomic roots**: ~200–250 core words (numbers, pronouns, basic verbs, body parts, natural elements)
- **Derived compounds**: ~1,500+ deducible words across sciences, professions, food, emotions, technology
- **Lexicon memorization burden**: drops from ~1,000 isolated entries to ~250 patterns
