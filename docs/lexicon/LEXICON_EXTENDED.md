## Formation Principles

These rules govern every word proposed in this document:

| Pattern | Example | Meaning |
|---------|---------|---------|
| `ROOT-ROOT` | `lern-hous` (existing) | transparent compound |
| `ROOT-po` | `muzika-maka-po` | profession (-po already established) |
| `ROOT-hous` | `arta-hous` | building/place |
| `ROOT-nes` | `tru-nes` | abstract noun from adjective |
| `ROOT-fors` | `fol-forsa` | natural force |
| `ROOT-lern` | `lifa-lerna` | field of study (alternative to -loji) |
| loan + vowel | `planite` | adapted loan ending in vowel |

**Compound length rule:** max 3 roots. If a concept needs 4+ roots, prefer an adapted loan.

**Loan adaptation rules:**
- No /θ/ → /z/ (`theory` → `teori`) or /t/ (`thin` → `tin`)
- No /ʒ/ → /j/ + vowel (`vision` → `vijon`)
- No schwa → nearest pure vowel (a/e/i/o/u)
- No geminate consonants → single (`coffee` → `kofi`)
- /æ/ → /a/ (`cat` → `kat`)

**Thematic vowel rule:** Any loan or root ending in an illegal single coda consonant (/d g p t k s f v ʃ/) receives a default thematic vowel /a/ to close the syllable legally (e.g. kod → koda, bug → buga).

**Banned final clusters:** These final clusters are illegal and MUST be restructured (not just suffixed): -tm, -mnt, -sm, -ʃn(-shn), -bl, -ks, -st, -rd, -rs, -tr, -ns, -nt, -nd, -kl, -dl, -lt, -lf, -nr, -dr, -kt, -sk, -pt, -nkr.

**Plural rule:** -n after vowel-final words, -en after consonant-final words. Morpheme order is root-NUMBER-case (e.g. man-en-se = 'of the men').

**Atom ceiling (two-tier):** a soft core target of ~200 atoms; domain registers (tech/science/arts) are an open class but every loan must carry a ≤3-root transparent compound alternative.

**-nes suffix:** the established suffix forms (`tru-nes`, `nof-nes`, `dep-nof`) stay as-is; standalone abstract nouns may take -nesa (trunesa) in isolation.

## 5.6 Loan Word Policy

### When to Borrow (Not Compound)

| Situation | Principle | Example |
|-----------|-----------|---------|
| Scientific terms with universal adoption | Keep recognizable | `atom`, `DNA`, `protein` |
| International acronyms | Adapt minimally | `IP-adresa`, `DNA` |
| Culturally specific artifacts | Adapt phonetically | `yoga → yoga`, `sushi → sushi` |
| Term shorter than any valid compound | Prefer loan | `etik` over `rait-rong-sistam` |

### Phonological Adaptation Rules

| Source sound | VELA rule | Example |
|-------------|-----------|---------|
| /θ/ "th" | → /z/ | theory → `teori` |
| /ʒ/ "zh" | → /j/ | vision → `vijon` |
| schwa /ə/ | → nearest pure vowel | problem → `problem` (o) |
| /æ/ "cat" | → /a/ | cat → `kat` |
| /ɔː/ "law" | → /o/ | law → `lo` |
| geminate CC | → single C | coffee → `kofi` |
| final impossible cluster | → add /a/ | strength → `strenga` |

### When NOT to Borrow

- A transparent compound exists with ≤ 3 roots
- The loan would collide with an existing word
- The concept is better captured by VELA's own semantic primitives (prefer `fol-forsa` over `graviti`)

### Cultural Loans (No Adaptation)

Proper nouns and highly culture-specific terms keep their original form:
`yoga`, `sushi`, `salsa`, `tango`, `safari`, `zen`, `karma`
