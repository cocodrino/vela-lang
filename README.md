# VELA — Lenguaje Construido

> Un lenguaje искусственный (constructed language / conlang) creado desde cero, con fonología, gramática, léxico y escritura propios.

## 📖 Sobre el Proyecto

VELA es un proyecto de lenguaje construido (conlang) diseñado para ser un idioma completo, naturalista y funcional — con sistema de escritura, gramática, vocabulario y reglas fonológicas propios.

El objetivo es crear no solo un set de palabras, sino un **sistema lingüístico coherente** que pueda:
- Ser aprendido y hablado
- Tener gramática consistente
- Evolución histórica interna (como las lenguas naturales)
- Aplicaciones en worldbuilding, arte, o uso personal

## 🎯 Objetivos del Lenguaje VELA

| Aspecto | Descripción |
|---------|------------|
| **Tipo** | Naturalista — suena como lengua orgánica, no artificial |
| **Familia** | A determinar (aislada o derivada de una fuente) |
| **Fonología** | A definir — objetivo: sonidos únicos y pronunciables |
| **Sistema de escritura** | Alfabeto propio o silabario propio |
| **Gramática** | Flexible — decide entre fusional, aglutinante, aislante |
| **Vocabulary** | Construcción interna (no kopi from English) |
| **Objetivo de uso** | Worldbuilding / arte / uso personal |
